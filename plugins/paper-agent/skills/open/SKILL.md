# 화면 열기

1. 이미 떠 있는지 확인한다: `lsof -i :8501 -sTCP:LISTEN`. 떠 있으면 3번으로 간다.
2. Bash 를 **백그라운드로** 실행한다: `"${CLAUDE_PLUGIN_ROOT}/bin/pa" app`
   - 처음 실행이면 패키지 설치로 1~2분 걸린다고 알린다.
   - 지금 작업 폴더의 `projects/` 를 읽는다. 다른 폴더에서 열면 프로젝트가 보이지 않는다.
3. 사용자에게 주소 `http://localhost:8501` 을 알려준다.
4. 화면 안내 한 줄: 연구 주제 설정(대화로 주제·키워드 정하기) → 찾기(읽을 논문 고르기) → 읽기(PDF와 분석, 형광펜 메모) → 모아보기(내 메모·연구 아이디어·보고서).
